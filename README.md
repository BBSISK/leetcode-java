# leetcode-java

![tests](https://github.com/BBSISK/leetcode-java/actions/workflows/test.yml/badge.svg)

My solutions to the [NeetCode 150](https://neetcode.io/practice) in Java, worked through alongside CS210 Algorithms and Data Structures on the Higher Diploma in Software Development at Maynooth University (2026–27).

Every solution has JUnit 5 tests, and the test suite runs on GitHub Actions on every push.

## How I work

- I write every solution myself. I use Claude as a coach: it picks the next problem, gives a hint if I'm stuck, and reviews my code after it passes.
- Each solution file starts with a short note: my approach, time and space complexity, and what I learned.
- When I improve a solution (for example from brute force to a hash map), the commit history shows both versions.

## Running the tests

```bash
mvn test
```

Requires Java 17+ and Maven.
